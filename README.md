# BudgetMate

A personal finance and budgeting web app: track income/expenses, set category
budgets with progress indicators, get spending predictions and anomaly
alerts, detect recurring transactions, set savings goals, run a what-if
spending simulator, and earn streaks/badges for staying under budget.

- **Backend:** Express (Node.js) + MySQL
- **Frontend:** React
- **Database:** MySQL (via XAMPP)

See the setup guide provided alongside this project for full step-by-step
installation instructions.

## Quick start (once dependencies are installed and MySQL is running)

```bash
# Terminal 1 — backend
cd server
npm install
npm run dev

# Terminal 2 — frontend
cd client
npm install
npm start
```

Backend runs on `http://localhost:5000`, frontend on `http://localhost:3000`.
